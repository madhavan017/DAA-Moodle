# Design and Analysis of Algorithms (DAA)

## 📌 About the Repository

This repository contains C programs related to **Design and Analysis of Algorithms (DAA)**. The programs cover time complexity analysis, greedy algorithms, dynamic programming, and competitive programming problems.

## 📚 Topics Covered

### 1. Finding Time Complexity of Algorithms

Programs that use the counter method to determine the number of operations performed by an algorithm.

* Problem 1: Finding Complexity Using Counter Method
* Problem 2: Finding Complexity Using Counter Method
* Problem 3: Finding Complexity Using Counter Method
* Problem 4: Finding Complexity Using Counter Method
* Problem 5: Finding Complexity Using Counter Method

### 2. Greedy Algorithms

Programs that demonstrate greedy approaches to solving algorithmic problems.

* **Coin Problem:** Finding the minimum number of coins using given denominations.
* **Cookies Problem:** Assigning cookies to children based on their requirements.
* **Burger Problem:** Solving a problem involving an array and sorting.
* **Array Sum Maximum Problem:** Calculating a maximum weighted sum of array elements.
* **Product of Array Elements – Minimum:** Minimizing the sum of products of corresponding array elements.

### 3. Divide and Conquer

This section includes dynamic programming problems.

* **Playing with Numbers:** Solving a number-based problem using dynamic programming.
* **Longest Common Subsequence (LCS):** Finding the longest subsequence common to two strings.
* **Longest Non-Decreasing Subsequence:** Finding the longest subsequence in which elements are in non-decreasing order.

### 4. Competitive Programming

Programs covering common array and searching problems with different time and space complexity approaches.

* Finding Duplicates – O(n²) Time Complexity, O(1) Space Complexity
* Finding Duplicates – O(n) Time Complexity, O(1) Space Complexity
* Printing the Intersection of Two Sorted Arrays – O(m × n) Time Complexity, O(1) Space Complexity
* Printing the Intersection of Two Sorted Arrays – O(m + n) Time Complexity, O(1) Space Complexity
* Pair with Difference – O(n²) Time Complexity, O(1) Space Complexity
* Pair with Difference – O(n) Time Complexity, O(1) Space Complexity

## 💻 Programming Language

The objective of this collection is to improve understanding of algorithm design, time complexity analysis, greedy strategies, dynamic programming, and competitive programming techniques.
